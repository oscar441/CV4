Diabetes Risk Prediction Web Application

Date: July 13, 2026

Professional Summary

This project is a production-style machine learning portfolio application for diabetes risk classification. It demonstrates an end-to-end workflow including data loading, validation, preprocessing, feature engineering, supervised learning, model evaluation, and deployment.

The application combines reproducible machine learning practices with a bilingual Flask web interface.

Key Features

  • Data preview
  • Automatic cleaning of invalid medical values
  • Logistic Regression training
  • Random Forest training
  • Confusion Matrix visualization
  • ROC Curve
  • Precision-Recall Curve
  • Feature Importance
  • Download trained models

Technologies Used

Python, Flask, pandas, NumPy, Scikit-learn, Logistic Regression, Random Forest, Feature Engineering, Model Evaluation, ROC-AUC, Precision-Recall, Joblib, Docker, Render

Engineering Highlights

ML Workflow

Structured pipeline design for data retrieval, validation, preprocessing, and feature engineering.

Model Comparison

Evaluation of multiple supervised approaches with confusion matrices, ROC, and precision-recall analysis.

Deployment

Containerized application packaging with deployment on Render for a production-style portfolio example.
