Professional Summary

This project focuses on extending and improving an existing Learning Management System to support educational institutions through better software engineering, deployment, database administration, usability improvements, and educational workflows.

The work emphasizes engineering decisions, maintainability, deployment, and performance rather than rebuilding an LMS from scratch.

Key Features

  • Interactive left sidebar navigation
  • Navigation improvements
  • Blade template improvements
  • Bulk content importer
  • Educational resource organization
  • Course management improvements
  • MySQL and MariaDB administration
  • SQL optimization and migration support
  • Backup and restoration workflows
  • Deployment on Hostinger with SSH and Composer
  • Performance optimization and troubleshooting
