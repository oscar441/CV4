Professional Summary

This project implements a rule-based adaptive learning decision system that simulates how a Learning Management System can support students and instructors using engagement, performance, and behavioral information.

The objective is to demonstrate explainable educational decision making before introducing machine learning models.

Key Features

  • Learning state inference
  • Student engagement analysis
  • Topic-level learning gap detection
  • Instructor advisory alerts
  • Personalized learning recommendations
  • Non-blocking interventions
  • Transparent decision logic

Technologies Used

Python, pandas, NumPy, Rule-based AI, Intelligent Systems, Decision Support, Explainable Logic, Human-in-the-loop, Educational Technology

Engineering Highlights

Decision Logic

Transparent rules were used to infer student needs and weigh engagement, performance, and behavioral signals.

Educational Support

The system prioritizes advisory actions that are explainable, practical, and suitable for human review.

Explainability

Emphasis was placed on clear reasoning so the decision process is understandable to educators and stakeholders.
